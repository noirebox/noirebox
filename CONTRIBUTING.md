# Contributing to NoireBox

NoireBox is becoming a product — source development now happens in a private
repository, so this repository no longer hosts code and cannot accept code
contributions.

You still can:

- **Open an issue** — bug reports on the published releases (through v0.21.0),
  documentation gaps, compliance questions;
- **Improve the docs** — PRs against `docs/`, the READMEs and the CHANGELOG
  are welcome;
- **Verify** — the released verifier and the
  [noirebox-verify action](https://github.com/marketplace/actions/noirebox-verify)
  stay open forever.

The open-source record — releases through v0.21.0, ADRs, audit receipts,
SCAR replays — remains public and MIT.
